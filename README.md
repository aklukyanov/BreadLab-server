# BreadLab

Помощник домашнего пекаря: расчёты, рецепты и документация выпечки.

Проект состоит из двух частей:
*   **Клиентская** (VK-бот + Redis для хранения сессий и состояний)
*   **Серверная** (Django API + PostgreSQL для данных и расчётов)

Взаимодействуют через HTTP API. Основной функционал покрыт тестами.

---

# Серверная часть: API для расчётов, хранения и обработки рецептов.


## Функционал

* **CRUD для рецептов:** создание, чтение, обновление и удаление рецептов.
* **Расчёт закваски:** пересчёт опары 50% <-> 100% влажности и умножение рецептов.
* **Дерево рецептов:** история экспериментов с визуализацией ветвления.
* **Веб-интерфейс:** дублирует функционал бота и выводит дерево рецептов.
* **LLM-интеграция:** распознавание рецептов по тексту и фото, редактирование на естественном языке (API для бота).

---

## Веб-интерфейс

Веб-интерфейс дублирует функционал VK-бота и работает с теми же данными в PostgreSQL. Основные возможности:

*   Дашборд со списком рецептов пользователя.
*   Просмотр, редактирование, удаление рецептов.
*   Дерево рецептов с визуализацией ветвления -- клик по ноде открывает рецепт, можно проследить историю экспериментов и понять, какой рецепт на основе какого был создан.
*   Калькуляторы закваски и пропорций.

## Стек

*   Python 3.14
*   Django / Django REST Framework
*   PostgreSQL
*   Ollama (LLM)
*   Nginx (реверс-прокси, балансировка)
*   pytest
*   Docker / docker-compose

---

## Инфраструктура

Все разворачивается через docker-compose:

*   **Nginx** -- реверс-прокси и балансировщик нагрузки.
*   **3 replica backend** -- Django-серверы за Nginx.
*   **PostgreSQL 15** -- основная база данных.

## Локальный запуск

1.  **Клонируйте репозиторий**
    ```bash
    git clone https://github.com/aklukyanov/BreadLab-server.git
    cd BreadLab-server
    ```

2.  **Создайте файл .env в корне проекта:**
    ```env
    DJANGO_SECRET_KEY=ваш_секретный_ключ
    POSTGRES_DB=breadlab-db
    POSTGRES_USER=breadlab_user
    POSTGRES_PASSWORD=пароль_для_базы
    OLLAMA_API_KEY=ключ_ollama_api
    ```

3.  **Запустите через Docker**
    ```bash
    docker-compose up --build
    ```
